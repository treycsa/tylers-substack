# tylers-substack

Working repo for Tyler Reynolds' Substack: a daily "Top 3 Repos" review. Tyler scans GitHub repos surfacing on LinkedIn, scores them on a public rubric, hand-tests the top 3, and gives a verdict on each: ADOPTED, TRIED / NOT ADOPTED, or WATCHING.

- `docs/BLUEPRINT.md`: audit, positioning, setup checklist, rubric, pipeline, growth plan
- `docs/SETUP_PROGRESS.md`: Substack setup checklist status
- `drafts/`: post drafts (template in `drafts/TEMPLATE.md`)
- `tested-daily/YYYY-MM-DD/`: reproducible test scripts, one folder per issue

AI disclosure: AI scores and drafts; Tyler runs the tests, writes the verdicts, and sets the labels.
